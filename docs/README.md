## Локальная память агента

В корне находится [AGENTS.md](../AGENTS.md) с инструкцией читать `.agent/memory.md` при работе над проектом. Память хранит локальное окружение, текущие решения, результаты последней проверки и незавершённую работу. Каталог `.agent/` исключён из Git: при новом клонировании памяти на другом компьютере не будет.

Открывай в агенте корень репозитория Space: проектные инструкции обнаруживаются относительно рабочего каталога. Файл памяти агент читает по инструкции в `AGENTS.md`. После существенной задачи агент обновляет память. Общие сведения переносит в документацию проекта, чтобы они были доступны всем участникам. Механизм проектных инструкций описан в [OpenAI Docs](https://learn.chatgpt.com/docs/agent-configuration/agents-md).
