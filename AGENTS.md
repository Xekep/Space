# Работа с Space

Space — Android-игра на Kotlin и Jetpack Compose. Модуль `:app` находится в `src/app`, Gradle запускается из корня репозитория.

## Контекст

- В начале задачи прочитай `docs/README.md` и локальную `.agent/memory.md`, если она существует. Затем открывай документы и код, относящиеся к задаче. При отсутствии памяти продолжай по документации и исходникам.
- `.agent/memory.md` — рабочие заметки конкретного checkout, а не источник истины о коде. Сверяй меняющиеся сведения с Git, исходниками и результатами проверок.
- После содержательных изменений обновляй локальную память: решения, проверенные результаты, ограничения и оставшаяся работа. Указывай дату; заменяй устаревшие сведения. Не сохраняй секреты и полный текст переписки.
- Устойчивые сведения об архитектуре и разработке сохраняй в `docs/`, результаты игровых изменений — в `docs/implementation-report.md`.

## Работа и проверки

- Сначала проверь `git status`. Сохраняй уже существующие изменения; коммит и push выполняй по явному запросу пользователя.
- Отвечай по-русски. Пользователь предпочитает компактный интерфейс, иконки и минимум подсказок. Текущий запрос пользователя имеет приоритет над этими заметками.
- Сборка: JDK 17, Android SDK 35. Команды и проверка на эмуляторе — в `docs/development.md`.
- Для изменений физики и боевых правил запускай относящиеся к ним unit-тесты; перед завершением большой итерации — debug/release проверки. Жесты, камеру и HUD проверяй Android-тестами. Для документации достаточно проверить ссылки и `git diff --check`.
- Сохраняй пользовательские миры, настройки и рекорды: для тестирования на используемом устройстве применяй `adb install -r` и `am instrument`. Gradle connected-тесты могут переустановить приложение.
- Новые строки UI добавляй во все пять локализаций и проверяй `python scripts/check-localizations.py`.
- Разделяй автоматизированные прохождения, визуальную проверку и испытания на настоящем телефоне. Измерение шага симуляции не означает измерение FPS.
